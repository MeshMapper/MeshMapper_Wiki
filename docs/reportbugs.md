# Report Bugs & Request Features

MeshMapper is actively being developed using community feedback, and bugs are expected.

You can submit a ticket using the guided form (also available from **About → Report Issue** on any map, and from the mobile app):

<a href="https://meshmapper.net?createticket" target="_blank" style="background-color: #007bff; color: white; padding: 10px 20px; text-decoration: none; border-radius: 5px; font-weight: bold; display: inline-block; margin: 10px 0;">Submit Bug or Feature Request</a>

In the MeshMapper Discord, you can also tag the bot with **`!bug`** or **`!feature`** followed by a description. See [Bot Commands](botcommands.md).

Alternatively, you can report bugs directly on the MeshMapper issue tracker on GitHub:

<https://github.com/MeshMapper/MeshMapper_Project>

We also welcome ideas and suggestions to improve MeshMapper. It's a community-driven project and all feedback is welcome.

!!! note
    Due to the size and activity of the community, these are the **only** ways to submit tickets. The developers may miss requests sent any other way.
