# MeshMapper Server v1.5.171

*Released November 2, 2026. Covers v1.5.162 to v1.5.171.*

## ✨ New
- **Personal API keys:** Every portal account can now make one [personal API key](../../personal-api-keys.md) for its own scripts, in **Profile Settings > API key**. It reads the [Profile API](../../profile-api.md) for any companion, and the [Leaderboard API](../../leaderboard-api.md) and [Observers API](../../observers-api.md) for the regions your linked companions have pinged in, plus the superregions that contain them.
- **Personal key limits:** 100 calls per UTC day and 10 per minute, shared by every API the key can call. Deleting the key and making a new one does not reset the day's count.
- **Profile API:** `get_profile.php?hex_id=` returns the profile the site shows for any companion: points, squares, awards and regions. Its `region_points` gives one line per region leaderboard the companion is on, each equal to that board right now.
- **Leaderboard API:** `get_leaderboard.php?region=` returns a region's or superregion's six top 10 boards, the same boards the site shows.
- **Observers API:** `get_observers.php?region=` lists a region's or superregion's MQTT observers and when each was last heard, the same list as the map's **Observers** button, read fresh on every call. Add `&pubkey=` with your observer's key (or at least its first 6 characters) to check just yours; hidden observers never appear.
- **Integration keys:** Keys on the default permissions now include the Profile, Leaderboard and Observers APIs.
- **Country keys:** A new kind of [integration key](../../api-keys.md#country-keys) covers every enabled region in one country, for example all of Canada, and picks up new regions with no key change. It works from any address, so it suits CI jobs on GitHub-hosted runners, but it does not include the Coverage API; ask MrAlders0n for one.
- **Global Map links:** Switch Region on the homepage and on every region page now starts with a **Global Map** row, and the homepage has an **Explore the Global Map** button at the bottom of its map. Both open global.meshmapper.net on the view you're looking at, and from a region page they keep your base map, coverage mode and frequency.
- **Rename your region:** Region admins can now rename their region in **Settings > Public Display**. Only the name people see changes: the region code, web address and data stay the same, the country at the end (such as ", CA") can't be changed, and each rename is recorded in History.
- **Rename a group:** Group admins can rename the group in **Public Display** on the group admin page, and each member region from its card on the group page.
- **Name rules:** A region or group name is 1 to 60 characters: letters in any language, digits, spaces and `. , - ( ) & /`. A typed `'` becomes `’`, and a name that breaks these rules stops the whole save.

## 🐛 Fixes
- **Profile points match the leaderboard:** Profiles, the portal Overview and the app now show the same points as the region leaderboards instead of a nightly copy that could lag behind them, so the Profile and Leaderboard APIs agree when you pull both. After you link a radio, its points move onto your account the next time each board updates, which can take up to 24 hours.
- **New radios on a leaderboard:** A radio that reaches a board before its first nightly sync now opens its profile.
