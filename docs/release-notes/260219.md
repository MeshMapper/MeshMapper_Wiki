# 🚀 MeshMapper Update (February 19, 2026)

### ✨ New Features

* **Notes for Repeaters and Companions** — Added ability to add notes to repeaters and companions in the admin panels. (Thanks Noodles)  [See More](../admins.md#data-management)

![Image](https://meshmapper.net/img/upload_20260219_092727_008ad65a.jpg)

* **Lock Repeater GPS** — Added option in admin panels to lock repeater GPS coordinates to prevent adverts from updating the location.  (Thanks jstockton)  [See More](../admins.md#repeaters)

![Image](https://meshmapper.net/img/upload_20260219_092831_4a3de45d.jpg)

* **Social Media Links** — Administrators can now add social media links to the "Region Info" page of their regions map. (Thanks bbrodka)  [See More](../admins.md#system-settings)

![Image](https://meshmapper.net/img/upload_20260219_092913_550d6acb.jpg)

![Image](https://meshmapper.net/img/upload_20260219_092605_43961f64.jpg)

* **Offline Observer Notifications** — Administrators can now opt-in to Discord notifications when an observer hasn't sent data to MeshMapper within the Stale Repeater Age time set on the admin page. (Thanks mrzarquon)  [Read more about it here](../admins.md#notifications)

### 🛠️ Improvements

* **Nomenclature** — Changed the "Administration" option on a regions map to "Region Info".  Changed "Contacts" to "Companions" in admin panels.
* **GPS Validation** — Added better GPS coordinates validation on manual edits of repeaters.
* **Neighbour Cleanup** — Improved neighbour cleanup logic to account for when repeater ID's get repurposed, or the repeater relocates.
* **DISC Pings** — Enhanced DISC ping association with repeaters to better handle if repeater gets relocated (association will now break).
* **Wardriving Updates** — Various adjustments to API's and map tile service for Wardriving app.
